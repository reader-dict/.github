# reader.dict

Clean, optimized dictionaries generated from Wiktionary data.

**reader-dict** parses Wiktionary dumps into compact, highly legible dictionary files tailored for e-readers, mobile devices, and desktop reading apps.

## Downloads

Ready-to-install dictionary files for your device are available on the main project page:
